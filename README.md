## ABOUT

_cleanUrls_ is a plugin for the open-source web publishing software called [Dotclear](https://www.dotclear.org).

> It removes diacritics and punctuation from URLs...

A [user guide in French](https://github.com/JcDenis/cleanURLs/blob/master/docs/fr/utilisation.md) is available.

## REQUIREMENTS

* Dotclear 2.39
* PHP 8.1+

## USAGE

First install _cleanURLs_, manualy from a zip package or from 
Dotclear plugins repository. (See Dotclear's documentation to know how do this)

Then when a post is created or updated, its URL is cleaned automagically:
accents are removed, punctuation is replaced by dashes.
